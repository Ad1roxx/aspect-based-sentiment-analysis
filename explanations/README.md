# Explanations

One file per sprint (`sprint-01.md`, `sprint-02.md`, …).

Each is a self-contained technical write-up of what that sprint built: what each component does,
why it is structured that way, the ML concepts involved, and the design decisions worth
scrutinising.

These are engineering notes, not tutorials — written while building, so the reasoning behind each
choice is recorded while it is still fresh rather than reconstructed afterwards.
